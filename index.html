02 / Architecture

GenAI & Backend Architecture Patterns

Production patterns I use to build reliable, observable LLM applications in TypeScript.

Multi-Model Waterfall Routing

Resilient orchestration across Gemini, Groq, and OpenRouter. If primary models hit rate limits or provider outages, automatic failover routes traffic to secondary models.

GeminiGroqOpenRouterFailover

Zero-Trust Zod Tool Registry

Every LLM tool call argument and structured JSON output is validated against strict Zod schemas. Hallucinated or malformed parameters are trapped before database execution.

ZodTool CallingType Safety

Hybrid RAG & Cosine Gating

Dense vector similarity (pgvector) combined with PostgreSQL full-text search (tsvector). Gated by strict distance thresholds (≤ 0.5): weak evidence triggers refusal instead of hallucination.

pgvectorHybrid SearchRAG Guardrails

Custom ReAct Agent Loops

Autonomous agent loop built in TypeScript without bloated frameworks. Orchestrates multi-step thought-action-observation cycles.
