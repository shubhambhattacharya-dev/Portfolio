About

Hey, I'm Shubham. Backend engineer in Vadodara, India. I'm the kind of person who actually enjoys debugging race conditions and thinking about what happens when a payment webhook arrives twice.

Got my BCA from Parul University, then spent two years going deep on AI agents, production APIs, and backend architecture. Honestly, I learned more from shipping broken things and fixing them than any course ever taught me.

Here's the thing — I treat AI like an untrusted API. Every response from an LLM goes through Zod schema validation before it gets anywhere near a database. No exceptions.

When I'm not building systems, I'm documenting my learning journey publicly — 60+ days of hands-on work covering RAG, vector databases, agent orchestration, and production LLMOps.

Engineering Principles

  • 🔒
    Validation at Boundaries

    Every input and every AI output gets validated through Zod before it touches the database. No raw data gets through.

  • ⚡
    CPU & Memory Safety

    Heavy work gets pushed to Redis/BullMQ workers so the API thread never blocks. Your request doesn't wait for someone else's background job to finish.

  • 💰
    Budget Guards

    Token usage gets estimated before any LLM call. Every request tracks its cost in both USD and INR, so there are no surprises on the bill.

  • 🛡️
    Human-in-the-Loop

    Anything involving real money above ₹200 gets held for a human to review. The AI doesn't get to decide on its own to issue refunds.

How I Build Agents

The architecture patterns behind every AI system I ship.

Agent Control Flow

State-machine driven routing with LangGraph.js. Every conversation follows a deterministic path: classify intent, route to the right handler, execute tools, validate output, and escalate to humans when confidence drops. No random prompt loops.

LangGraph.jsState MachinesHITL

Multi-Provider LLM Orchestration

Abstracted provider layer with per-persona routing, automatic fallbacks, and cost/latency tradeoffs. If Gemini is down, the agent seamlessly switches to Groq or OpenRouter. Every provider swap is logged and traced.

GeminiGroqOpenRouterFallbacks

Retrieval Pipeline

Hybrid retrieval combining vector similarity (pgvector) with lexical signals. Ingestion pipelines handle document parsing, chunking, and embedding with quality controls. Every retrieval result gets ranked before reaching the LLM context window.

pgvectorEmbeddingsRerankingRAG

Memory Architecture

Two-tier memory: long-term cross-session knowledge stored in the vector DB, and short-term per-thread state managed in Redis. Clear contracts between them so the agent remembers what matters and forgets what doesn't.

Long-termPer-threadRedispgvector

Observability & Cost Tracking

Every LLM call is traced end-to-end. Token usage, latency, and cost (USD/INR) tracked per request using tiktoken WASM. Errors get structured logs with full context so production debugging takes minutes, not hours.

LangfuseOpenTelemetrytiktokenSentry

Safety & Validation

Every AI output passes through Zod schema validation before touching any database. Financial decisions above thresholds get held for human review. Prompt injection shielding prevents malicious inputs from hijacking agent behavior.

ZodHITLInjection Shield
